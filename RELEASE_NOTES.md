🎉 Prima release di **Analizzatore Spazio**!

App Android per analizzare lo spazio di archiviazione del dispositivo.

### ✨ Funzionalità
- Grafico ad anello (donut chart) con ripartizione dello spazio utilizzato
- Analisi per categoria: app, immagini, video, audio, documenti e file di sistema
- Dettaglio per singola categoria con navigazione gerarchica dei file
- Formattazione automatica delle dimensioni (B, KB, MB, GB)
- Supporto landscape e portrait
- Apertura app e file direttamente dalla scansione
- Pulsante per aggiornare manualmente l'analisi
- Gestione permessi (media, accesso utilizzo, accesso completo ai file)

### 📦 Download
- [Analizzatore-Spazio.apk](link/attacco/alla/release) — Android 8.0+ (minSdk 26)

### 🔧 Requisiti
- Android 8.0 (API 26) o superiore
- Permesso di accesso ai file per l'analisi completa

### ⚙️ Note tecniche
- Realizzata in Kotlin con Jetpack Compose
- Material 3
